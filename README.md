Portofolio Dessert Chef

Website portofolio pastry & dessert chef, dibuat pakai HTML, CSS, dan JavaScript. Ada 3 bagian: Home, About, dan Menu. Menu dessert bisa difilter per kategori (cake/pastry/cokelat) pakai JS, dan tampilannya responsif di desktop, tablet, dan mobile.

Menggunakan:
1. HTML5
2. CSS3
3. JS (DOM Manipulation)
